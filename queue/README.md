# queue — 올릴 것들을 여기 쌓아둔다

날짜 폴더를 만들어두면 **그날 저녁 18:07에 알아서 올라간다.**
한 달치를 미리 만들어두고 컴퓨터를 꺼놔도 된다.

```
queue/
  2026-09-29/
    01.png        ← 표지
    02.png
    ...
    10.png        ← 최대 10장
    caption.txt   ← 본문 + 해시태그
  2026-10-02/
    ...
```

## 규칙

- 폴더 이름은 **올릴 날짜** (`YYYY-MM-DD`, 한국시간 기준)
- 이미지는 **파일 이름 순서대로** 올라간다 → `01`, `02` 처럼 두 자리로
- `.png` `.jpg` `.jpeg` 만 인식
- 1장이면 단일 게시물, 2장 이상이면 캐러셀
- 10장 넘으면 앞 10장만 쓴다
- `caption.txt` 없으면 캡션 없이 올라간다

## 올라가고 나면

그 폴더는 자동으로 `published/` 로 옮겨진다. 지우지 않아도 된다.

## 그날 폴더가 없으면

그냥 아무것도 안 올리고 조용히 끝난다. 에러 아니다.
